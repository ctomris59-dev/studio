## Configuration fix in the repository

The **example** Nginx HTTPS apex redirect now contains:

```nginx
add_header Strict-Transport-Security "max-age=31536000" always;
return 308 https://www.studiotasker.com$request_uri;
```

The `always` qualifier ensures the HSTS header is present even on redirects. It is **not** added to the HTTP (port 80) redirect. The canonical `www` site gets HSTS from Next.js already; avoid adding a second header in Nginx or accidentally hiding the upstream security headers. The patch does **not** turn on `includeSubDomains` or `preload`, as those require a separate domain-wide review.
